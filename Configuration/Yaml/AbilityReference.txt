====================================================================
 VALHEIM ITEM ENHANCEMENTS - ABILITY ID REFERENCE
 Complete list of supported Ability IDs across configuration files
====================================================================

─── Item.yml (Weapons / Tools / General / Accessories) ───

  WeaponDamage              All damage types bonus (%)
  WeaponBackstab            Sneak attack / backstab multiplier (+x)
  WeaponAttackStamina       Attack stamina cost reduction (%)
  WeaponAttackEitr          Staff spellcast eitr cost reduction (%)
  MaxDurability             Maximum durability increase (%)
  WeightReduction           Item weight reduction (%)
  CarryWeightBonus          Maximum carry weight bonus (flat units)

─── Armor.yml (Armor / Shields / Mobility) ───

  ArmorFlat                 Flat armor bonus (+flat units)
  ArmorPercent              Percentage armor bonus (%)
  ArmorMovementPenaltyReduction  Heavy armor movement speed penalty reduction (%)
  EitrRegen                 Eitr regeneration rate bonus (%)

  ShieldBlockPower          Shield block power bonus (%)
  ShieldDeflectionForce     Shield deflection force bonus (%)
  ShieldTimedBlock          Parry bonus multiplier (+x)
  ShieldBlockStaminaReduction  Block stamina cost reduction (%)

  DodgeStaminaReduction     Dodge roll stamina cost reduction (%)
  RunStaminaReduction       Sprint stamina cost reduction (%)
  JumpStaminaReduction      Jump stamina cost reduction (%)

─── Cheat.yml (Cheat Mode — Active only when EnableCheatAbilities: true) ───

  MaxHealth                 Maximum health capacity bonus (flat units)
  MaxStamina                Maximum stamina capacity bonus (flat units)
  MaxEitr                   Maximum eitr capacity bonus (flat units)
  HealthRegen               Health regeneration multiplier (%)
  StaminaRegen              Stamina regeneration multiplier (%)
  HealingMultiplier         Healing received multiplier (%)

====================================================================
 YAML Syntax & Usage Example
====================================================================

  Levels:
    <LevelNumber>:
      - Ability: <Ability ID>
        Value: <Incremental value gained at this level>

  Example:
    Levels:
      1:
        - Ability: WeaponDamage
          Value: 5.0        # +5% Weapon Damage
        - Ability: MaxDurability
          Value: 10.0       # +10% Max Durability
      5:
        - Ability: CarryWeightBonus
          Value: 25.0       # +25 Max Carry Weight
